# CrocoDocs fonts

CrocoDocs uses Open Sans for reading, controls and ordinary headings. The product name uses the supplied Haettenschweiler face with the same 12-degree forward slant as Call-a-Croc on the sibling Crimson Crocs website. Fonts are self-hosted through `next/font/local`.

`haettenschweiler.woff2` was converted without subsetting from `../crimsoncrocs/public/fonts/haettenschweiler.ttf`, supplied by Matthew for that project on 2026-09-28 and reused here at his request. It retains its original font names and notices. This supplied brand font is separate from the open-source fonts below; the SIL Open Font License does not apply to it.

Retrieved from the official Google Fonts CSS API on 2026-10-14:

`https://fonts.googleapis.com/css2?family=Open+Sans:ital,wght@0,400..700;1,400..700&family=Oswald:wght@600&display=swap`

- `open-sans-normal-latin.woff2`: Open Sans variable, weights 400–700, normal.
- `open-sans-italic-latin.woff2`: Open Sans variable, weights 400–700, italic.
- `oswald-600-latin.woff2`: Oswald, weight 600, retained from the earlier theme but no longer loaded.

Sources and licenses: [Open Sans](https://github.com/google/fonts/tree/main/ofl/opensans), [Oswald](https://github.com/google/fonts/tree/main/ofl/oswald). Both are distributed under the SIL Open Font License 1.1; the accompanying `opensans-OFL.txt` and `oswald-OFL.txt` retain the copyright notices and full terms. Existing Poppins files are retained but are no longer loaded.
