## Start with the problem

A library is optional code maintained outside your robot project. It can save implementation time, but it also adds APIs, dependencies, version compatibility, and maintenance work. Read the project's current installation guide and check which FTC SDK version it supports before adding it.

This directory covers tools with their own pages here. API examples and release numbers can change; each article links to the project's official documentation or source repository.

## Path following and autonomous

- [Pedro Pathing](./pedro-pathing) — build and follow a first field path with Pedro 3; the page includes a Java OpMode example.
- [Road Runner](./road-runner) — build a Road Runner 1.0 route with the official FTC Quickstart.

## Robot architecture and control

- [NextFTC](./nextftc) — create mechanisms, connect gamepad triggers, and run commands. The page includes servo and intake examples for v2.
- [Mercurial](./mercurial) — create and schedule a command with the Dairy Foundation framework.
- [FTCLib](./ftclib) — compose and schedule commands with FTCLib's command framework.

## Tuning and development

- [FTC Dashboard](./ftc-dashboard) — add telemetry and tune live configuration variables with code.
- [Panels](./panels) — expose a live-tunable value and inspect robot telemetry.
- [Sloth](./sloth) — deploy eligible TeamCode changes with its Gradle task; use a full install for dependencies and other unsupported changes.

## Vision

- [EasyOpenCV](../sensors-and-vision/easyopencv/easyopencv-basics) — OpenCV pipelines integrated with FTC camera workflows. It is a community library; follow its upstream documentation and check compatibility with your SDK.
- [VisionPortal and AprilTags](../sensors-and-vision/vision-overview) — FTC SDK vision APIs and related guides.

## Before you install

1. Confirm the FTC SDK version used by your robot project.
2. Read the library's current official installation and migration instructions.
3. Check that every repository and artifact in the Gradle example still exists.
4. Add one library at a time and sync Gradle.
5. Build and test on the Control Hub before relying on it in a match.

A version number copied from an old article can stop resolving or pull incompatible code. Where versions change often, these pages link to the official release page instead of guessing a version.
