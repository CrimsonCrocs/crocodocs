## What is Panels?

[Panels](https://panels.bylazar.com/) is a browser dashboard and plugin system for FTC robots. The official project describes tools for OpMode control, telemetry, field and graph views, capture/replay, runtime configurables, Limelight support, gamepads, and custom plugins. Availability depends on which plugins your project includes.

## Installation

Panels has changed significantly over time. Use the official [installation documentation](https://panels.bylazar.com/docs/com.bylazar.docs/) or the current Java/Kotlin Quickstart linked from the [official GitHub organization](https://github.com/ftcontrol). Copy the artifact coordinates and version that match your FTC SDK and language setup; old `fullpanels` versions and Sloth variants may not match current releases.

<Callout type="warn" title="Check SDK compatibility">
Panels releases are built against particular FTC SDK versions. Confirm the current prerequisites in the official installation guide before updating Panels or the SDK. Kotlin projects may also need a matching Kotlin Gradle plugin version.
</Callout>

## Connect and use it

After installing and deploying the matching project, connect a browser to the robot network and follow the address printed or documented by that Quickstart. The IP address and port depend on the project configuration; do not assume that an address from an older version still applies.

Use the telemetry and graph tools to inspect behavior while testing. Runtime configurables are useful for tuning, but record known-good values in your source control. Capture and replay can help investigate test data; it does not replace checking robot behavior on the field.

## Expose a value you can tune

One practical first use is to expose a motor limit so the team can adjust it in the Panels Configurables plugin while watching telemetry. Panels' Configurables plugin reads mutable `public static` Java fields from a class marked with `@Configurable`:

<Tabs items={['Java', 'Kotlin']}>
<Tab value="Java">

```java
import com.bylazar.configurables.annotations.Configurable;

@Configurable
public final class DriveTuning {
    public static double MAX_TEST_POWER = 0.20;
}
```

</Tab>
<Tab value="Kotlin">

```kotlin
import com.bylazar.configurables.annotations.Configurable

@Configurable
object DriveTuning {
    @JvmField var MAX_TEST_POWER = 0.20
}
```

</Tab>
</Tabs>

Read the field when you set motor power so a live change can affect the next loop:

<Tabs items={['Java', 'Kotlin']}>
<Tab value="Java">

```java
double requested = -gamepad1.left_stick_y * DriveTuning.MAX_TEST_POWER;
leftMotor.setPower(requested);
rightMotor.setPower(requested);
telemetry.addData("Test power limit", "%.2f", DriveTuning.MAX_TEST_POWER);
telemetry.addData("Requested power", "%.2f", requested);
telemetry.update();
```

</Tab>
<Tab value="Kotlin">

```kotlin
val requested = -gamepad1.left_stick_y * DriveTuning.MAX_TEST_POWER
leftMotor.power = requested
rightMotor.power = requested
telemetry.addData("Test power limit", "%.2f", DriveTuning.MAX_TEST_POWER)
telemetry.addData("Requested power", "%.2f", requested)
telemetry.update()
```

</Tab>
</Tabs>

The variable changes the chosen command limit; it does not measure whether the robot is moving straight or safely. Begin with the robot on blocks, then test at low power on an open floor. Write a known-good value into your source code after tuning. For dependency coordinates and setup, copy the Java or Kotlin Quickstart linked by the [Panels documentation](https://panels.bylazar.com/docs/com.bylazar.docs/); the plugin API and compatible versions change over time.

## Plugins

Panels is plugin-driven. Its official project lists OpMode control, telemetry, field view, graph view, capture, configurables, Limelight support, gamepads, camera stream, battery and ping information, and integrated documentation. Use the [current plugin documentation](https://panels.bylazar.com/docs/com.bylazar.docs/) for installation and APIs. Plugin names and installation steps can change, so verify the selected plugin's release details before adding it.

## Panels and FTC Dashboard

Both tools can support telemetry and robot development. Compare their current plugin sets, existing team code, SDK compatibility, and setup cost. Panels has a plugin model; FTC Dashboard provides its own telemetry, live configuration, field, graph, and camera features. Neither replaces careful match testing.
