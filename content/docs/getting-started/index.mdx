## Programming tools [#start-here]

FIRST recommends beginning with **Blocks**, including for students who have programmed before. It is a quick way to learn the FTC Control System and test simple OpModes. When you are ready to write text, choose **OnBot Java** or **Android Studio**.

| Tool | Best starting point | Where code is edited |
| --- | --- | --- |
| Blocks | New programmers and visual learners | Browser connected to the Robot Controller |
| OnBot Java | Teams learning text-based Java | Browser connected to the Robot Controller |
| Android Studio | Teams needing a full IDE, Git, or external libraries | Android Studio project on a computer |

These are FTC programming tools. Android Studio is an IDE; Java and Blocks are programming languages/tools. Kotlin is possible in Android Studio with the required project setup, but it is not one of the three standard programming tools in FIRST's current comparison guide.

## Robot workflow [#learn-the-robot-workflow]

Each program is an **OpMode** that runs on the Robot Controller after a team selects it on the Driver Station. Before writing code, configure the robot's motors and sensors in the Robot Controller app. Use the same device names in the program as in the hardware configuration.

Start with one motor or servo, then add gamepad input and sensor feedback. Test mechanisms with the robot safely supported and keep motor power limited while bringing up new code.
