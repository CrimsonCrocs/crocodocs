## Overview [#what-is-blocks]

FTC Blocks is a visual programming tool served by the Robot Controller. You use a browser on a computer or compatible device to create, edit, save, and build OpModes with connected blocks. No separate editor installation is needed; the Robot Controller and browser must be connected through the robot's Program & Manage network.

FIRST recommends Blocks as the starting tool, including for teams that expect to use Java later. Blocks programs are saved and run on the Robot Controller. Keep a downloaded copy of your `.blk` files with the team's source and backups.

## First steps

1. Configure the robot's devices in the Robot Controller app.
2. Connect your browser to the Program & Manage address shown on the Robot Controller.
3. Open the **Blocks** programming tool and create a sample OpMode.
4. Read the FTC tutorial for setup, building, running, and saving Blocks programs.

The address depends on the Robot Controller device and network configuration. Use the address shown on the device rather than assuming an IP address.

## Java transition [#moving-to-text-based-code]

Blocks is its own visual programming environment. It can help you learn sequencing, conditions, loops, and hardware control, but it does not automatically make a Java project for Android Studio. When you move to text, learn the Java syntax and FTC SDK APIs using the official [OnBot Java](./onbot-java) or [Android Studio](./android-studio) guides.
