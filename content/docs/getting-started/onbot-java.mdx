## Overview [#what-is-onbot-java]

OnBot Java is a text-based Java editor served by the Robot Controller. You connect a browser to the Program & Manage server, edit Java source there, build it on the robot controller, and select the resulting OpMode from the Driver Station.

It does not require Android Studio, but you still need to understand Java and the FTC SDK's hardware APIs. Your code and build environment live on the Robot Controller, so save backups and use version control for team code where practical.

## First steps

1. Configure the robot hardware in the Robot Controller app.
2. Connect to the device's Program & Manage address.
3. Open **OnBot Java**, create an OpMode from a sample, and use the editor's build control.
4. Fix build messages before selecting the OpMode on the Driver Station.

Use the address shown by the connected Robot Controller. FTC Docs lists common addresses for Control Hubs and Robot Controller phones, but network configuration can vary.
