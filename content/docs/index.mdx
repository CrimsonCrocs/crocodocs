<Wordmark size="large" /> is a student-written guide to FTC engineering, programming, and portfolios.

Choose **Engineering** in the top navigation for robot design, mechanisms, fabrication, wiring, and testing. **Programming** contains Java and Kotlin, robot control, vision, autonomous routines, and commonly used libraries.

**Portfolio** covers documenting your season, preparing evidence for awards, and judging, with detailed studies of Inspire portfolios.

<Callout>
  This site is an independent student project and is not affiliated with or endorsed by FIRST. Competition rules and software APIs change; use the linked official sources for current requirements.
</Callout>

Articles combine explanations with links to official documentation. Robot behavior depends on the SDK version, hardware, and implementation, so test examples safely on your own robot.

<Callout type="warn" title="Season-specific information">
The current season page covers BIOBUZZ (2026–27). Always check the official competition manual and team updates before relying on game rules, scoring, or robot legality.
</Callout>

## Philosophy

CrocoDocs puts FTC explanations and examples in one reference so students can learn without piecing together forum posts, videos, and codebases. Students write and maintain the articles, checking technical details against official documentation and source code.
