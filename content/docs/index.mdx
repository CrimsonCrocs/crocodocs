<Wordmark textOnly /> is a student-written guide to robotics programming.

This handbook focuses on **FIRST Tech Challenge (FTC)** programming: Java and Kotlin, robot control, vision, autonomous routines, and commonly used libraries.

<Callout>
  This site is an independent student project and is not affiliated with or endorsed by FIRST. Competition rules and software APIs change; use the linked official sources for current requirements.
</Callout>

Articles combine explanations with links to official documentation. Robot behavior depends on the SDK version, hardware, and implementation, so test examples safely on your own robot.

Some pages may recompile and rephrase information from various sources to make
it more accessible or relevant. However, if an existing resource already covers
a topic thoroughly and clearly, we will link to it directly instead of rewriting
it. Additionally, sources and references used in each page will be listed where
applicable.

<Callout type="warn" title="Season-specific information">
The current season page covers BIOBUZZ (2026–27). Always check the official competition manual and team updates before relying on game rules, scoring, or robot legality.
</Callout>

## Philosophy

The goal of <Wordmark textOnly /> is to make technical knowledge in FIRST robotics more
accessible, accurate, and student-driven. Many programming concepts are
scattered across forums, videos, and codebases. This site aims to unify them into a
single, structured reference.
