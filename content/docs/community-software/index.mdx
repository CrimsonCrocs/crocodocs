This section covers newer projects from the FTC community. Some are code you copy into TeamCode; others supply models that run on a separate camera. Each guide explains what you install, how to try it, and what to check before using it on a robot.

## Projects

| Project | What it provides | First test |
| --- | --- | --- |
| [Blaze FTC](./blaze-ftc) | Native hardware communication with a Java/Kotlin interface and Rust examples | Count bulk-read callbacks without powering motors |
| [OpenLoop](./openloop) | Source-copy helpers for timed autonomous movement | Calibrate a short move and measure its travel |
| [Hive Vision](./hive-vision) | BIOBUZZ detection models for Limelight, plus separate webcam code | Load the model and inspect detections with the robot still |

For path followers, command frameworks, and tuning tools, see [Libraries](../libraries).
